# MakeCode-Tutorials: Maqueen Grand Prix

Tutorials für den Robotik-Workshop „Maqueen Grand Prix“ von FRANCOR e. V.
(BBC micro:bit V2 + DFRobot Maqueen Plus V3). Die Workshop-Seite liegt in
<https://github.com/franc0r/francor-dfrobot-workshop>.

| Datei | Station | Link |
|---|---|---|
| `erster-kontakt.md` | 1 – Erster Kontakt | <https://makecode.microbit.org/#tutorial:github:franc0r/makecode-maqueen-tutorials/erster-kontakt> |

Auf der Messe gibt es nur langsames Internet. Den Link deshalb beim Aufbau auf jedem
Arbeitsplatz einmal öffnen; danach nimmt MakeCode das Tutorial aus dem Browser-Cache.

Testen ohne Push: `tutorial-test.html` im Workshop-Repo (`microbit/tutorial/`) per
Doppelklick öffnen und die `.md` wählen.
